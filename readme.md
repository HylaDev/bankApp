# bank app

Welcome to your bank app, the app to manage your banks accounts and transactions.

## Requirements
- Node.js (latest LTS version recommended)
- npm (comes with Node.js)

## Installation
1. Clone the project repository:
   ```bash
   git clone <repository-url>
   cd <project-directory>
   ```

2. Install the required Node.js dependencies:
   ```bash
   npm install
   ```

## Running the Backend Server
1. Start the server:
   ```bash
   npm start
   ```
   Ensure the backend server is running before accessing the front end.

## Running the Frontend
1. Open your browser.
2. In the address bar, type:
   ```
   index.html
   ```
   This will launch the front end of the application.

## Notes
- The backend is powered by Node.js.
- The front end is built using HTML, CSS, JavaScript, and AJAX.
